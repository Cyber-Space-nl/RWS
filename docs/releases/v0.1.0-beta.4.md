# RWS v0.1.0-beta.4

**Experimental prerelease.** This beta is not a stable or production-readiness claim. The
standalone download targets Linux x86-64 with GNU libc. Linux 5.6 or newer is required for
contained static-file opening; compatibility outside the tested environment is not established.

## What's new

- Static GET supports multipart byte ranges, bounded to 16 ranges and 1 MiB of selected data.
- Buffered identity and gzip representations have distinct strong SHA-256 ETags, with
  `If-Match` and `If-None-Match` support.
- `If-Range` honors a matching strong identity ETag or a matching Last-Modified date at least
  60 seconds old. Unsupported values result in the full response.

Streamed files do not emit ETags. Requests exceeding multipart bounds receive the full response;
HEAD ignores Range. Cached content and validators follow the cache revalidation interval. See the
[README](../../README.md) and [security testing](../SECURITY_TESTING.md).

## Installation and limits

The archive contains `rws`, `rws-ws-load` and `rws-bench`, a configuration example,
documentation, a dependency-license inventory and collected license/notice files. It does **not**
include a systemd installer or units. Verify checksums before use:

```bash
sha256sum -c SHA256SUMS
tar -xzf rws-v0.1.0-beta.4-x86_64-unknown-linux-gnu.tar.gz
cd rws-v0.1.0-beta.4-x86_64-unknown-linux-gnu
sha256sum -c BINARY_SHA256SUMS
bin/rws --version
```

For a systemd installation from source, see [UBUNTU_INSTALL.md](../../UBUNTU_INSTALL.md).
Back up the existing installation and test a rollback before upgrading. The unified service has
not yet been tested under real systemd or with PHP-FPM. RWS requires trusted site roots and an
appropriately isolated PHP-FPM service. HTTP/2, slow clients and sustained overload need further
validation. The proxy has per-request buffering limits and does not proxy WebSocket upgrades or
generate trusted forwarding headers. Independent external review and human review of license and
distribution obligations remain outstanding. The bundled inventory is not a legal opinion.

## Build

On x86-64 Ubuntu 24.04 with Python 3.12 and Rust 1.88 or newer, commit the intended source,
unset build override variables, then run:

```bash
python3 tools/release/assemble.py --output /tmp/rws-beta-4
cd /tmp/rws-beta-4
sha256sum -c SHA256SUMS
```

The script builds from the committed revision and collects license metadata, notices and
checksums. Build-host libc does not establish minimum supported libc, and builds are not claimed
to be byte-for-byte reproducible across environments.
