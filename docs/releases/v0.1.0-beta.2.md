# RWS v0.1.0-beta.2

**Experimental prerelease.** This beta is not a stable or production-readiness claim. The
standalone download targets Linux x86-64 with GNU libc. Linux 5.6 or newer is required for
contained static-file opening; compatibility outside the tested environment is not established.

## What's new

- Static GET supports a single byte range, including suffix and open-ended ranges.
- Static responses provide `Last-Modified` and support date-based conditional requests.
- Optional gzip for eligible static files and optional Linux directory listings can be enabled
  per site; both are off by default.
- The README includes usage examples and updated, explicitly bounded benchmark results.

Multiple ranges and ETag generation are not implemented. Requests with `If-Range` receive the
complete representation. Gzip is limited to eligible files and bounded worker concurrency;
directory listings expose visible filenames and require `/proc/self/fd`. See the
[README](../../README.md#configuration) and [security testing](../SECURITY_TESTING.md).

## Installation and limits

The archive contains four standalone executables, configuration examples, documentation,
dependency-license inventory and collected license/notice files. It does **not** include a
systemd installer or units. Verify checksums before use:

```bash
sha256sum -c SHA256SUMS
tar -xzf rws-v0.1.0-beta.2-x86_64-unknown-linux-gnu.tar.gz
cd rws-v0.1.0-beta.2-x86_64-unknown-linux-gnu
sha256sum -c BINARY_SHA256SUMS
bin/rws-simple --version
```

For a systemd installation from source, see [UBUNTU_INSTALL.md](../../UBUNTU_INSTALL.md).
Back up binaries, units, configuration, logrotate settings and site data before upgrading; test
the matching rollback procedure in an isolated environment. The `rsw` to `rws` rename is not
automatic. No VPS deployment is implied by publishing this package.

RWS still requires trusted site roots and an appropriately isolated PHP-FPM service. HTTP/2,
slow clients and sustained overload need further validation. The proxy has per-request buffering
limits and does not proxy WebSocket upgrades or generate trusted forwarding headers. Independent
external review and human review of license and distribution obligations remain outstanding.
The bundled dependency inventory is not a legal opinion.

## Build

On x86-64 Ubuntu 24.04 with Python 3.12 and Rust 1.88 or newer, commit the intended source,
unset build override variables, then run:

```bash
python3 tools/release/assemble.py --output /tmp/rws-beta-2
cd /tmp/rws-beta-2
sha256sum -c SHA256SUMS
```

The output directory must not exist. The script builds from the committed revision and collects
license metadata, notices and checksums. Build-host libc does not establish minimum supported
libc, and builds are not claimed to be byte-for-byte reproducible across environments.
