# RWS v0.1.0-beta.10

**Experimental prerelease.** The standalone download targets Linux x86-64 with GNU libc, built on Ubuntu 22.04. Linux 5.6 or newer is required for contained file opening. This release does not establish production readiness or independent security review.

## Changes since beta.9

- Update `url` from 2.5.8 to 2.5.9 to address [RUSTSEC-2026-0592](https://rustsec.org/advisories/RUSTSEC-2026-0592), a stack overflow in `Url::origin()` for nested `blob:` URLs. The reachability of this issue in RWS has not been established.
- Update `form_urlencoded` from 1.2.2 to 1.2.3 as part of the dependency resolution.
- Add an [early live-use report](../validation/insaider-early-live-observations-2026-11.md) with separate historical production observations and their limitations.

## Installation

The archive contains `rws`, `rws-ws-load`, `rws-bench`, configuration, documentation and dependency license material. Systemd installers, units and helpers are in the matching source tree, not the standalone archive. See [UBUNTU_INSTALL.md](../../UBUNTU_INSTALL.md) and [beta.9 notes](v0.1.0-beta.9.md).

```bash
sha256sum -c SHA256SUMS
tar -xzf rws-v0.1.0-beta.10-x86_64-unknown-linux-gnu.tar.gz
cd rws-v0.1.0-beta.10-x86_64-unknown-linux-gnu
sha256sum -c BINARY_SHA256SUMS
bin/rws --version
```

Back up existing installations and test rollback before upgrading. Independent external security review and human review of distribution obligations remain outstanding.

## Build

On x86-64 Ubuntu 22.04 with binutils, Python supporting tarfile's `data` filter and Rust 1.88+:

```bash
python3 tools/release/assemble.py --output /tmp/rws-beta-10
```

Commit source changes and unset build override variables first. The builder rejects binaries referencing glibc symbols newer than 2.35. Builds are not claimed to be byte-for-byte reproducible across environments.
