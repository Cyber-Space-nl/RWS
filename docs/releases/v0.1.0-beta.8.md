# RWS v0.1.0-beta.8

**Experimental prerelease.** The standalone download targets Linux x86-64 with GNU libc, built on Ubuntu 22.04. Linux 5.6 or newer is required for contained file opening. This release does not establish production readiness or independent security review.

## Changes since beta.7

- Preserve multiple Cookie header fields in their original order when passing requests to PHP-FPM. This fixes missing cookies and PHP sessions with HTTP/2.
- Include the request Referer header in site access logs and HTTP error logs; a missing header is logged as `-`. Referer values may contain sensitive information: protect and retain logs accordingly.

These changes have also been used in a separate source build serving [insaider.nl](https://insaider.nl/). That source build and this release archive are distinct artifacts.

## Installation

The archive contains `rws`, `rws-ws-load`, `rws-bench`, configuration, documentation and dependency license material. Systemd installers, units and helpers are in the matching source tree, not the standalone archive. See [UBUNTU_INSTALL.md](../../UBUNTU_INSTALL.md) and [beta.7 notes](v0.1.0-beta.7.md) for configuration and prior features.

```bash
sha256sum -c SHA256SUMS
tar -xzf rws-v0.1.0-beta.8-x86_64-unknown-linux-gnu.tar.gz
cd rws-v0.1.0-beta.8-x86_64-unknown-linux-gnu
sha256sum -c BINARY_SHA256SUMS
bin/rws --version
```

Back up existing installations and test rollback before upgrading. Independent external security review and human review of distribution obligations remain outstanding.

## Build

On x86-64 Ubuntu 22.04 with binutils, Python supporting tarfile's `data` filter and Rust 1.88+:

```bash
python3 tools/release/assemble.py --output /tmp/rws-beta-8
```

Commit source changes and unset build override variables first. The builder rejects binaries referencing glibc symbols newer than 2.35. Builds are not claimed to be byte-for-byte reproducible across environments.
