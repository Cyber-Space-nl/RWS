# RWS v0.1.0-beta.6

**Experimental prerelease.** This is not a stable or production-readiness claim. The standalone
download targets Linux x86-64 with GNU libc and is built on Ubuntu 22.04. Linux 5.6 or newer is
required for contained static-file opening. Compatibility outside tested environments is not
established.

## What's new

- The source systemd unit no longer hard-codes PHP 8.3 startup ordering. A new source helper,
  `scripts/configure-php-fpm.sh`, creates an explicit drop-in for selected local PHP-FPM services.
- The helper requests and orders the selected services but does not change configured sockets or
  restart RWS. It refuses to overwrite a different existing drop-in. RWS can still start if
  PHP-FPM fails; check the service and socket.
- A full-reboot Ubuntu 22.04 VM test covered PHP 8.1 startup ordering, static-only operation,
  invalid inputs and drop-in preservation. It used the beta.5 server binary with the new unit and
  helper, not the beta.6 binary. See [the test report](../validation/ubuntu-22.04-php-order.md).

## Installation and limits

The archive contains `rws`, `rws-ws-load`, `rws-bench`, configuration, documentation and
dependency-license material. It does **not** include the systemd installer, unit or helper;
those are in the matching source tree. Verify checksums before use:

```bash
sha256sum -c SHA256SUMS
tar -xzf rws-v0.1.0-beta.6-x86_64-unknown-linux-gnu.tar.gz
cd rws-v0.1.0-beta.6-x86_64-unknown-linux-gnu
sha256sum -c BINARY_SHA256SUMS
bin/rws --version
```

For systemd installation from source, see [UBUNTU_INSTALL.md](../../UBUNTU_INSTALL.md). Back up
existing installations and test rollback before upgrading. RWS requires trusted site roots and
appropriately isolated PHP-FPM. HTTP/2, slow clients and sustained overload need further
validation. The proxy has per-request buffering limits and does not proxy WebSocket upgrades or
generate trusted forwarding headers. Independent external review and human review of license and
distribution obligations remain outstanding.

## Build

Build on x86-64 Ubuntu 22.04 with binutils, a Python 3 installation supporting tarfile's `data`
extraction filter, and Rust 1.88 or newer. Commit the source, unset build override variables and run:

```bash
python3 tools/release/assemble.py --output /tmp/rws-beta-6
cd /tmp/rws-beta-6
sha256sum -c SHA256SUMS
```

The builder checks dynamically referenced glibc symbol versions against 2.35. Symbol checks and
the build-host libc do not alone guarantee compatibility. Builds are not claimed to be
byte-for-byte reproducible across environments.
