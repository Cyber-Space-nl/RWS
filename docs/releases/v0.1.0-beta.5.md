# RWS v0.1.0-beta.5

**Experimental prerelease.** This is not a stable or production-readiness claim. The standalone
download targets Linux x86-64 with GNU libc and is built on Ubuntu 22.04. Linux 5.6 or newer is
required for contained static-file opening. Compatibility outside the tested environments is not
established.

## What's new

- The x86-64 archive targets the Ubuntu 22.04 glibc baseline. The beta.4 server binary required
  GLIBC 2.38 and could not start on Ubuntu 22.04.
- Streamed static files on Linux receive weak metadata-based ETags and support `If-None-Match`.
  These tags are not content hashes and depend on the filesystem updating metadata when contents
  change. They do not satisfy `If-Match` or ETag-based `If-Range`.
- The release builder rejects binaries requiring glibc symbols newer than 2.35.

## Installation and limits

The archive contains `rws`, `rws-ws-load` and `rws-bench`, configuration, documentation, a
dependency-license inventory and collected license/notice files. It does **not** include a
systemd installer or units. Verify checksums before use:

```bash
sha256sum -c SHA256SUMS
tar -xzf rws-v0.1.0-beta.5-x86_64-unknown-linux-gnu.tar.gz
cd rws-v0.1.0-beta.5-x86_64-unknown-linux-gnu
sha256sum -c BINARY_SHA256SUMS
bin/rws --version
```

For systemd installation from source, see [UBUNTU_INSTALL.md](../../UBUNTU_INSTALL.md). Back up
the existing installation and test a rollback before upgrading. The unified service has not yet
been tested under real systemd or with PHP-FPM. RWS requires trusted site roots and an isolated
PHP-FPM service. HTTP/2, slow clients and sustained overload need further validation. The proxy
has per-request buffering limits and does not proxy WebSocket upgrades or generate trusted
forwarding headers. Independent external review and human review of license and distribution
obligations remain outstanding. The bundled inventory is not a legal opinion.

## Build

Build on x86-64 Ubuntu 22.04 with a current Python 3 installation supporting tarfile's `data`
extraction filter, binutils, and Rust 1.88 or newer. Commit the intended source, unset build
override variables, then run:

```bash
python3 tools/release/assemble.py --output /tmp/rws-beta-5
cd /tmp/rws-beta-5
sha256sum -c SHA256SUMS
```

The builder checks the dynamic symbol versions of all three binaries against glibc 2.35. Symbol
checks and the build-host libc do not alone guarantee compatibility. Builds are not claimed to
be byte-for-byte reproducible across environments.
