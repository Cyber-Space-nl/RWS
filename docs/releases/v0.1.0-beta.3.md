# RWS v0.1.0-beta.3

**Experimental prerelease.** This beta is not a stable or production-readiness claim. The
standalone download targets Linux x86-64 with GNU libc. Linux 5.6 or newer is required for
contained static-file opening; compatibility outside the tested environment is not established.

## What's new

- One `rws` server binary combines static files, PHP-FPM and WebSocket echo with optional HTTP
  reverse proxying and adaptive WebSocket scheduling.
- One example configuration, source installer and service replace the former server variants.
- Beta.2's single byte ranges, date-based conditional requests, optional gzip and Linux directory
  listings remain available. Multiple ranges and ETag generation are not implemented.

Existing installations require manual migration. Back up binaries, units, configuration,
logrotate settings and site data and test a rollback in an isolated environment before upgrading.
The new service has not yet been tested under real systemd or with PHP-FPM. See the
[README](../../README.md) and [security testing](../SECURITY_TESTING.md).

## Installation and limits

The archive contains `rws`, `rws-ws-load` and `rws-bench`, configuration examples, documentation,
dependency-license inventory and collected license/notice files. It does **not** include a
systemd installer or units. Verify checksums before use:

```bash
sha256sum -c SHA256SUMS
tar -xzf rws-v0.1.0-beta.3-x86_64-unknown-linux-gnu.tar.gz
cd rws-v0.1.0-beta.3-x86_64-unknown-linux-gnu
sha256sum -c BINARY_SHA256SUMS
bin/rws --version
```

For a systemd installation from source, see [UBUNTU_INSTALL.md](../../UBUNTU_INSTALL.md).
RWS requires trusted site roots and an appropriately isolated PHP-FPM service. HTTP/2, slow
clients and sustained overload need further validation. The proxy has per-request buffering
limits and does not proxy WebSocket upgrades or generate trusted forwarding headers. Independent
external review and human review of license and distribution obligations remain outstanding.
The bundled dependency inventory is not a legal opinion.

## Build

On x86-64 Ubuntu 24.04 with Python 3.12 and Rust 1.88 or newer, commit the intended source,
unset build override variables, then run:

```bash
python3 tools/release/assemble.py --output /tmp/rws-beta-3
cd /tmp/rws-beta-3
sha256sum -c SHA256SUMS
```

The script builds from the committed revision and collects license metadata, notices and
checksums. Build-host libc does not establish minimum supported libc, and builds are not claimed
to be byte-for-byte reproducible across environments.
